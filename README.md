## Задание

Класс `OnlineSalesRegisterCollector` отвечает за работу онлайн-кассы. Он содержит:

- список `name_items` — товары в чеке;
- переменную `number_items` — количество товаров в чеке;
- словарь `item_price` — товары магазина и их стоимость;
- словарь `tax_rate` — налоговая ставка на товары: 10% или 20% от стоимости.

Прекод:

```python
import datetime

class OnlineSalesRegisterCollector:

    def __init__(self):
        self.__name_items = []
        self.__number_items = 0
        self.__item_price = {'чипсы': 50, 'кола': 100, 'печенье': 45, 'молоко': 55, 'кефир': 70}
        self.__tax_rate = {'чипсы': 20, 'кола': 20, 'печенье': 20, 'молоко': 10, 'кефир': 10}

    ...  # допиши код здесь
```

Нужно добавить в класс восемь обязательных методов и один дополнительный.

### Сводка методов

| № | Метод | Что делает |
|---|-------|-----------|
| 1 | `name_items`, `number_items` | Геттеры (`@property`) для приватных атрибутов |
| 2 | `add_item_to_cheque(name)` | Добавляет товар в чек |
| 3 | `delete_item_from_check(name)` | Удаляет товар из чека |
| 4 | `check_amount()` | Считает общую сумму покупок |
| 5 | `twenty_percent_tax_calculation()` | Считает НДС для товаров со ставкой 20% |
| 6 | `ten_percent_tax_calculation()` | Считает НДС для товаров со ставкой 10% |
| 7 | `total_tax()` | Возвращает общую сумму НДС по чеку |
| 8 | `get_telephone_number(telephone_number)` | Статический метод, возвращает номер телефона покупателя |
| ⭐ | `get_date_and_time()` | Дополнительный статический метод, возвращает дату и время покупки |

---

### 1. Геттеры

В чеке печатают названия товаров и их количество, но атрибуты `name_items` и `number_items` приватные — к ним нельзя обратиться напрямую.

Напиши геттеры, которые получают значения `name_items` и `number_items`. Используй декоратор `@property`.

### 2. Добавление товара в чек

Метод `add_item_to_cheque(name)` принимает название товара:

| Условие | Результат |
|---------|-----------|
| В названии 0 или больше 40 символов | `ValueError('Нельзя добавить товар, если в его названии нет символов или их больше 40')` |
| Названия нет в `item_price` | `NameError('Позиция отсутствует в товарном справочнике')` |
| Иначе | Товар добавляется в `name_items`, `number_items` увеличивается на 1 |

### 3. Удаление товара из чека

Метод `delete_item_from_check(name)`:

| Условие | Результат |
|---------|-----------|
| Товара нет в `name_items` | `NameError('Позиция отсутствует в чеке')` |
| Иначе | Товар удаляется из `name_items`, `number_items` уменьшается на 1 |

### 4. Общая стоимость товаров

Метод `check_amount()` содержит пустой список `total` и добавляет в него цены товаров из `name_items`, взятые из словаря `item_price`.

- Если в чеке больше 10 товаров, сумма возвращается со скидкой 10%.
- Иначе возвращается полная сумма.

### 5. НДС для товаров со ставкой 20%

Метод `twenty_percent_tax_calculation()` содержит:

- пустой список `twenty_percent_tax` — сюда попадают товары из `name_items` со ставкой 20% в `tax_rate`;
- пустой список `total` — сюда попадают цены товаров из `twenty_percent_tax`.

Возвращает общую сумму НДС для позиций с максимальной ставкой: **НДС = стоимость товара × 0,2**. Учти скидку, если товаров больше 10.

### 6. НДС для товаров со ставкой 10%

Метод `ten_percent_tax_calculation()` устроен так же:

- пустой список `ten_percent_tax` — товары из `name_items` со ставкой 10%;
- пустой список `total` — их цены.

Возвращает общую сумму НДС: **НДС = стоимость товара × 0,1**. Учти скидку, если товаров больше 10.

### 7. Общая сумма налогов

Метод `total_tax()` возвращает общую сумму НДС по чеку.

### 8. Номер телефона покупателя

Статический метод `get_telephone_number(telephone_number)` принимает десять цифр после `+7`:

| Условие | Результат |
|---------|-----------|
| Передано не целое число | `ValueError('Необходимо ввести цифры')` |
| Больше 10 символов | `ValueError('Необходимо ввести 10 цифр после "+7"')` |
| Иначе | Полный номер телефона |

### Подсказки

- Чтобы принудительно вызвать исключение, используй оператор `raise`.
- Чтобы исключение вывело конкретное сообщение, передай текст в скобках: `ValueError('Недопустимое значение')`.
- Добавить элемент в список — `append()`, удалить — `remove()`.
- Сумму элементов списка считает функция `sum()`.
- Общий НДС — это сумма результатов `ten_percent_tax_calculation()` и `twenty_percent_tax_calculation()`.
- Полный номер телефона собери через f-строку, добавив `+7` к `telephone_number`.
